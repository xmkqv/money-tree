# iec 81346-1

- IEC 81346-1 establishes general principles for structuring systems and their information [scope][standard]
- a reference designation identifies an object for creating and retrieving information [scope][standard]
- the 2022 edition adds the type aspect [foreword][preview]

```text:types
ObjectOccurrence
Aspect = Function | Product | Location | Type | Other
AspectPrefix = Function:"=" | Product:"-" | Location:"+" |
               Type:"%" | Other:"#"
```

# aspect structures

- the function aspect concerns what an object is intended to do or does [§4.2][preview]
- the product aspect concerns how an object is constituted [§4.2][preview]
- the location aspect concerns the object's intended or actual space [§4.2][preview]
- the type aspect concerns the group of objects with shared characteristics [§4.2][preview]

```text:surface
Structure(aspect) = ObjectOccurrence + PartitiveRelation
sameObject(FunctionOccurrence, ProductOccurrence,
           LocationOccurrence, TypeOccurrence)
```

# designation

- a multi-level reference designation concatenates single-level designations along one structure [§6.2.2][preview]
- a reference designation set can collect designations from different aspect structures [clause 7][preview]

```text:surface
SingleLevelDesignation = AspectPrefix + Identifier
MultiLevelDesignation = SingleLevelDesignation+
ReferenceDesignationSet = MultiLevelDesignation+
```

# assurance

- the standard gives rules for unambiguous reference designations [scope][standard]
- a designation attached to a realised component acts as a key to information across documents [scope][standard]

```text:surface
identify(ReferenceDesignation, context) -> one ObjectOccurrence
inv:ambiguous designation -> violation
```
