## notes

- pure agent SDKs (CrewAI, LangGraph, AutoGen→Microsoft Agent Framework, OpenAI Agents SDK, MetaGPT, CAMEL/OWL, Google ADK) are a different layer — libraries for building one agent run, not platforms managing a persistent fleet. Excluded from the table as a category mismatch; CrewAI's paid AMP tier is the closest any of them get to governance.
- budget enforcement (hard $/token caps) is the scarcest real feature industry-wide — confirmed in only OpenHands, martin-loop, omnigent, agent-teams-ai, CellCog (consumption billing) among everything surveyed.
- two vacancies opened in 2026: Vibe Kanban (27.7k★, shut down April) and Antfarm (2.5k★, stalled February) — both had real distribution and no active maintainer as of this writing.
- multi-node mesh (agent state moving across laptop/server/VPS/phone) is Fusion's rarest axis — only ai-maestro (explicit machine-to-machine migration), Orca (desktop+mobile+VPS), t3code (web+mobile+desktop), and nimbalyst (desktop+mobile companion) match it; every other project assumes one host.
- `herdrdev/herdr` and `ogulcancelik/herdr` resolve to the same repo (27.4k★) — the org rename redirects, both links work.
- license hygiene is uneven at the top: superset, automaker, loki-mode, agent-kanban and AgentsMesh ship without a standard OSI license file (`NOASSERTION`); AgentsMesh is explicitly BSL-1.1.
