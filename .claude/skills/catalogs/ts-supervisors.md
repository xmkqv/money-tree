# ts-supervisors

- subject: TS-biased libraries for supervising agents — intercepting an agent's questions/permission prompts and routing the answer (to a human channel, a second LLM, or a supervising agent)
- three layers in one table: HITL/question-routing MCC/MCP servers, Claude Code CLI wrappers/session supervisors, and agent frameworks with first-class interrupt→answer-inject primitives
- window: 2026-02-17 through 2026-08-17
- verified: `gh api repos/{owner}/{repo}` on 2026-08-17 unless marked stale
- fleet-scale orchestration platforms are out of scope

## notes

### answer injection

- **corrected 2026-08-17 (round-2 adversarial sweep): agent-answers-agent tools DO exist, but none has adoption** — sim4dim/claude-supervisor is a full match (hook-intercepts AskUserQuestion, `claude -p` answers, injects option or free-form text via `updatedInput`; 1★, single-author, AI mode off by default); Supervisor/maximizeGPT (transcript-tail + LLM triage, types answers; 1★), Yash-Awasthi-02/claude-supervisor (stream-json wrapper + BYOK answerer; 0★), and aoaoe (tmux capture + LLM reasoner `send_input`; 12★) match B+C with wrapper-level interception. Everything that fully matches is 0–12★. The pattern is proven, the market is unclaimed.
- **`updatedInput` on a PreToolUse `allow` is the official answer-injection channel for AskUserQuestion** (code.claude.com/docs/en/hooks; issues #12605, #28273) — this supersedes earlier reads that hooks cannot answer. Public uptake is thin: a Sourcegraph sweep found only 2 repos using it, and the big one (claude-code-harness, 3.1k★) deliberately refuses to LLM-invent answers, injecting config-sourced answers only.
- Anthropic shipped then reverted (v2.1.198 → v2.1.200, Jul 2026) a 60s AskUserQuestion auto-continue that injected "proceed using your best judgment" — a null-answer, and its reversal signals first-party caution about auto-answering the question surface.
- adjacent shipped products with undisclosed or conversation-level mechanisms: Overnight/workovernight.com (LLM predicts the user's next message from history, feeds `claude -p`), Scape (scape.work, "watchdogs field the routine questions", mechanism undisclosed), supervis (DeepSeek drives the loop so prompts never occur).
- MCP elicitation spec explicitly permits non-human answer sources but no shipped client does it — a spec-compliant novel place to ship the pattern; ACP's `session/request_permission` is likewise client-answered and protocol-legal for an LLM client, unused.

### apis

- **the approval sub-surface is commoditized in-harness**: Claude Code auto mode (Sonnet classifier, 2026-03-25), Codex CLI `--approve-for-me` (0.147.0, 2026-08-07), Cursor Auto-review (3.6, 2026-05-29), Goose SmartApprove (`PermissionJudge`) — all native LLM answerers of their own permission prompts, all allow/deny/escalate only. The free-text question surface remains human-relay in every ecosystem checked (opencode, Codex, Gemini CLI, Aider, Amp, Devin, ACP clients, MCP elicitation).
- `needsApproval` is the de-facto tool-level HITL API name across Vercel AI SDK, OpenAI Agents JS, and Temporal's integration — approval-gates are table stakes now, free-form answer-inject is the differentiator.
- interrupt idioms converged to two camps: checkpoint-graph (LangGraph.js `interrupt()`; pre-interrupt code re-runs on resume) vs durable-promise/snapshot (Mastra, VoltAgent, Inngest, Restate, Temporal; journaled, no re-run).
- claude's stream-json protocol remains officially undocumented (anthropics/claude-code#24612); every serious wrapper (happy, cui, claudecodeui) re-implements parsing privately.

### coverage

- dead genres: desktop-popup HITL dialogs (interactive-feedback-mcp 1.7k★ frozen 2025-05, GongRzhe archived, interactive-mcp 351★ quiet since 2025-11) → replaced by Slack/Telegram/Discord routing; third-party auto-responders (claude-composer 671★, Claude-Autopilot, ClaudeAutoResponder — all dormant since mid-2025) → killed by native auto mode; typed-hooks kits (claude-hooks 386★ dead, carabiner stalled) → only cc-hooks-ts maintained.
- license hygiene: claudecodeui is AGPL-3.0; HumanLayer, mcp-feedback-enhanced, call-a-human-mcp are NOASSERTION; claude-code-telegram has no license file.
- excluded: agent-squad (7.7k★, router only, no pause primitive), Motia (deprecated into Rust `iii` engine 2026-04), PocketFlow-Typescript (dead 2025-03), pal-mcp-server ex-zen (11.7k★ LLM-council router, quiet since 2025-12, Python).
