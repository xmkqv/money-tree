# bad-plan

- count(true facts) ≥ 1 → bad plan

## checks

- [ ] misplaced = does the plan assign a responsibility to the wrong architectural layer?
- [ ] novel = does the plan invent terminology where the existing lexicon is sufficient?
- [ ] redundant = does the plan invent code where existing functionality is sufficient?
- [ ] mis-scoped = does the plan omit the original problem or solve beyond it?
- [ ] unidiomatic = would the proposed code violate established language or repository idioms?
- [ ] unaware = does the plan neglect relevant libraries, tools, or environment constraints?
- [ ] inertial = does the plan preserve existing code or patterns without current justification?
